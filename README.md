# Rashna Rahman Richita — Personal Portfolio

Live site: https://rashna-rahman.github.io/

This version keeps **every file in one place (no folders)**, so it can be uploaded to GitHub with
**Add file → Upload files → choose your files** in one go.

| File | What it is |
|---|---|
| `index.html` | All page text and sections |
| `style.css` | All design (colors at the very top) |
| `script.js` | Links, projects, video, CV / cover letter settings (at the very top) |
| `profile.jpg` | Profile photo |
| `CV.pdf` | CV used by every Download CV button |
| `offline-files.js` | Saved copy of the CV for downloads when the page is opened offline |
| `favicon.svg` | Browser tab icon |
| `offline-copy-maker.html` | Refreshes `offline-files.js` if you change your CV |

## Updating later
- **New CV:** upload a new file named exactly `CV.pdf`. It replaces the old one.
- **Cover letter:** upload `Cover_Letter.pdf`, then in `script.js` set
  `coverLetter: "Cover_Letter.pdf"` (inside `DOCUMENTS`) and upload `script.js` again.
- **Video:** upload your video named `introduction.mp4`.
- **New photo:** upload a new `profile.jpg`.

GitHub Pages updates the live site 1–2 minutes after each upload.
