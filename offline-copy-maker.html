Offline copy maker

Use this only if you open the portfolio by double-clicking index.html. In that mode browsers block normal downloads, so the site uses a saved copy of your PDFs from assets/documents/offline-files.js. On GitHub Pages or Live Server you don’t need this.

  1. Choose your latest CV and (optionally) your cover letter.
  2. Click Create offline-files.js.
  3. Move the downloaded file into assets/documents/, replacing the old one.
